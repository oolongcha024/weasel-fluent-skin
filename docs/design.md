# 皮肤设计

本仓库的主产物是 [Fluent 2 风格的小狼毫皮肤](../skins/fluent-2/weasel.custom.yaml)。预览工具用于观察这份配置的实际含义，设计调整应落到正式 YAML 中。

## 当前取舍

| 要素 | 当前配置与意图 |
| --- | --- |
| 配色 | 浅色使用中性浅灰浮层，深色使用中性深灰浮层；蓝色承担选中提示 |
| 高亮 | 以低强度蓝色背景和强调色竖线提示选中项；序号与注释使用中性辅助色，让候选正文更突出 |
| 形状 | 窗口圆角 8，候选高亮圆角 4；最终贴边圆角由小狼毫的布局规则决定 |
| 层次 | 单层阴影与细边框表现候选窗口的浮起感 |
| 字体 | 中文优先 Microsoft YaHei UI / Microsoft YaHei；序号优先 Segoe UI |
| 布局 | 横排候选、内嵌编码；正文 12 磅，序号与注释 9 磅 |

这里的数值是当前设计选择，不是对 Fluent 2 规范的完整复刻。颜色、圆角、阴影等具体值以 YAML 为准，修改它们时同步更新有变化的设计依据。

小狼毫使用单层阴影，当前皮肤没有实现 Acrylic 或 Mica 材质。字体回退、原生高亮标记的最小宽度、边距修正与阴影缓冲都会影响最终观感，需通过预览和 Windows 实机共同判断。

## 修改原则

浅色与深色在同一份 YAML 中维护，共享布局。新增变体前应有明确用途，避免为微小参数差异复制整份配置。

先确定要改善的输入体验，例如长候选是否易读、序号是否拥挤、选中态是否清楚，再调整参数。工具应忠实显示配置，不能通过额外 CSS 修饰候选窗口来掩盖皮肤问题。

默认场景见 [previews/scenes.json](../previews/scenes.json)，覆盖日常输入、长词与中英混排、特殊字符。遇到新的典型输入情况时，在这里补充可重复观察的场景。

发布前记录 Windows 版本、小狼毫版本、字体和系统缩放，并观察浅色与深色。浏览器展示图片与 Windows 实机截图应明确标注来源，验证流程见[开发说明](development.md)。
